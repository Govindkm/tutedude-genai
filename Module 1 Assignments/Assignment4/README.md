# Assignment 4 — File Handling (Read, Write, Append, Modes)

This folder contains **only** the File Handling assignment (assignment ID `695fbd65cfb436b316fa3b7c`).

## Contents

- `Assignment4.ipynb` — the assignment notebook (Tasks 1-7)
- `sales_data.txt` — data file used/updated by Tasks 1-4
- `products.txt` — data file used/updated by Task 5 (format: `Product | Price`)
- `discount_report.txt` — data file generated by Task 7

## How to Run

1. Open `Assignment4.ipynb` in VS Code or Jupyter, with this folder as the working directory (all file paths in the notebook are relative).
2. Run the cells from top to bottom (`Run All`).
3. Some cells prompt for input via `input()`:
   - **Task 5** asks for 3 product names and prices — entries are saved to `products.txt` as `Product | Price`.
   - **Task 6** asks for a filename to check/read — try an existing file (e.g. `sales_data.txt`) and a non-existent one to see both branches.
   - **Task 7** asks for a discount percentage to generate `discount_report.txt`.
4. Re-running Task 1 will overwrite `sales_data.txt`, and Task 3 will append to it again — run the notebook top to bottom in a single pass for consistent output.
